# Agent API Documentation

## 1. Overview

The Intelligent Agent Platform provides an API endpoint for processing user queries through a supervisor-based multi-agent system.

The supervisor identifies the query type and routes it to the appropriate specialist agent.

## 2. Endpoint

**Method:** `POST`

**URL:** `/api/v1/agents/chat`

**Content-Type:** `application/json`

## 3. Request Body

```json
{
  "user_query": "Explain Java Stream API with an example"
}
```

### Request Fields

| Field | Type | Required | Description |
|---|---|---|---|
| user_query | string | Yes | User's query to process |

The query must contain at least one character.

## 4. Successful Response

**Status Code:** `200 OK`

Example:

```json
{
  "selected_agent": "coding",
  "agent_response": "Java Stream API provides a functional approach to processing collections..."
}
```

### Response Fields

| Field | Type | Description |
|---|---|---|
| selected_agent | string | Specialist agent selected by the supervisor |
| agent_response | string | Response generated by the selected agent |

Possible agent values:

- `coding`
- `math`
- `research`
- `general`

The actual selected agent depends on the supervisor's classification.

## 5. Error Responses

### Invalid Request

**Status Code:** `422 Unprocessable Entity`

Returned when the request body is invalid or `user_query` is empty.

### Agent Processing Failure

**Status Code:** `502 Bad Gateway`

Returned when agent processing fails.

Example:

```json
{
  "detail": "Agent processing failed: error details"
}
```

## 6. Example Requests

### Coding Query

```json
{
  "user_query": "Explain Java Stream API with examples"
}
```

Expected routing: `coding`

### Math Query

```json
{
  "user_query": "Calculate the derivative of x squared"
}
```

Expected routing: `math`

### Research Query

```json
{
  "user_query": "Compare LangGraph, CrewAI, and AutoGen based on their official documentation."
}
```

Expected routing: `research`

### General Query

```json
{
  "user_query": "What is artificial intelligence?"
}
```

Expected routing: `general`

These are example routing expectations; actual routing depends on the supervisor's classification logic.

## 7. Testing the API

Start the FastAPI application:

```powershell
uvicorn app.main:app --reload
```

Open the interactive API documentation:

`http://127.0.0.1:8000/docs`

Find the `POST /api/v1/agents/chat` endpoint, select **Try it out**, enter a request body, and execute it.

## 8. Architecture

The API follows this processing flow:

```text
Client Request
     |
     v
FastAPI Agent Endpoint
     |
     v
LangGraph Workflow
     |
     v
Supervisor Agent
     |
     v
Selected Specialist Agent
     |
     v
LLM Service
     |
     v
API Response
```

The Research Agent additionally uses the Web Search Service and Evidence Extractor to process research queries.
